Challenges Faced & How We Overcame Them
Challenge What Happened How We Resolved It Status
Dataset path discovery NIH dataset was not at the expected /kaggle/input path — os.walk() hung indefinitely on 112k files Built a single-pass dictionary scan using os.listdir() per folder — indexed all 112,120 images in under 10 seconds Resolved
Severe class imbalance Pneumonia represents only 1.3% of dataset (55:1 ratio) — model predicted Normal for everything Implemented pos_weight per condition in BCEWithLogitsLoss (Pneumonia weight: 78×) to penalise missing rare conditions Resolved
Kaggle session timeouts Sessions timed out mid-training, losing all variables and model checkpoints Consolidated entire pipeline into one self-contained cell; used Quick Save instead of Save & Run All to preserve checkpoints Resolved
GPU quota exhaustion Kaggle T4 GPU quota (30 hrs/week) was running low due to long training runs Subsampled to 20k training images — reduced epoch time from 31 min to 7 min. Full dataset training planned for Week 6 Resolved
PyTorch API deprecation register_backward_hook deprecated in newer PyTorch — Grad-CAM implementation failed Switched to register_full_backward_hook which is the current recommended API Resolved
Grayscale to RGB conversion NIH X-rays are grayscale but EfficientNet expects 3-channel RGB input Added .convert('RGB') in the Dataset class to repeat the single channel 3 times during loading Resolved
Current Challenge

⚠ Infiltration vs Effusion Misclassification

Our model currently confuses Infiltration with Effusion in certain cases. Both conditions produce similar radiographic opacity patterns — diffuse haziness in the lung fields — making them visually difficult to distinguish, especially on a 20k training subset.

Impact: Infiltration AUC is 0.6793, our lowest performing condition. The model tends to predict Effusion (AUC 0.8555) when uncertain, since Effusion is better represented in training data.

Clinical context: While the exact condition may be misclassified, the model still correctly flags these cases as HIGH or MEDIUM priority abnormal — meaning no dangerous cases are missed, only the specific label differs.

📋 Plan to Overcome

1
Full dataset training (Week 6): Training on all 89,826 images instead of 20k will give the model 4× more Infiltration examples, expected to push AUC above 0.75
2
Ensemble model: Combining B0+B3 predictions averages out individual model biases — early tests show Infiltration improving with ensemble
3
Condition-specific augmentation: Apply stronger augmentation specifically for Infiltration cases to increase effective training samples
4
Threshold tuning: Adjust classification thresholds per condition during Week 4 calibration to optimize sensitivity for underperforming classes
